# File systems

**Task description:** At a high level, learn about the following topics:

- **The file system abstraction:** what it is, what its purpose is, and why programs use it.
- **Directories:** what role they play in organizing and locating files.
- **FAT file systems:** how files are represented, how the file allocation table is used, and what tradeoffs this design has.
- **Extents:** what they are and why they can be useful for representing large sequential regions of a file.
