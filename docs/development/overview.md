# Development Overview

This directory documents how to work on the active application code.

| File | Scope |
|---|---|
| `backend.md` | FastAPI structure, service boundaries, database access, schema conventions. |
| `frontend.md` | React route tree, API clients, auth state, server state, type conventions. |
| `testing.md` | Backend test categories, commands, dependency notes, server-backed checks. |
| `logging-and-errors.md` | Backend exception helpers, stage-tagged errors, structured service logs. |

Related operational setup is documented in `docs/operations/`.
