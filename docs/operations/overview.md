# Operations Overview

This directory documents how Pensum Piloten is configured, started, deployed, and maintained.

| File | Scope |
|---|---|
| `local-development.md` | Local backend/frontend setup, service requirements, course material workflow, checks. |
| `configuration.md` | Environment variables, provider selection, retrieval settings, upload limits, startup data settings. |
| `docker-deployment.md` | Compose services, Dockerfiles, Nginx proxying, volumes, health checks. |
| `database.md` | Startup table creation, compatibility DDL, admin bootstrap, seed data, database connectivity. |
| `course-materials.md` | Upload staging, supported file types, versioned rebuilds, failure handling. |
